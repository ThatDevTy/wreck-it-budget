Welcome to Wreck-It Budget! A fun way to tackle your household bills and debts. This application is a C# backend built on ASP.NET core on .NET 10, it uses Angular for its front end written in TypeScript, the app talks to SQL Server through EF Core. Inspired by an 80s style arcade game; instead of breaking down buildings, we are here to break down debt and keep the lights on with Oscar the Wrecker, Mary who keeps the lights on, and Billy, who guides you along this journey. So join the fun, and actually see progress being made!
